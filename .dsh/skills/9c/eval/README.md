# 评测：流程 + 结果

评测分两层，**先冻结题目，再看新视频/改框架**，否则就是拿答案改模型。

## 第一层：流程与证据（现在就能跑）

题目在 [`../eval.md`](../eval.md)，12 道，评分表也在那里。关注：

- 三因子是否齐全、是否带报告期与数据来源；
- 该否决时是否果断否决；
- 有没有编造数字、预测涨跌、给点位。

## 第二层：结果（有历史案例后跑）

`cases.example.jsonl` 是模板；把真实案例写进 `cases.jsonl`（可放在仓库外或本地忽略），
每条至少包含：

```json
{
  "id": "eval-2025-001",
  "input": "/史诗级韭菜 中国平安",
  "as_of": "2025-01-02",
  "expected": {
    "stance": "avoid",
    "must_include": ["高杠杆", "≤5%"],
    "must_not": ["目标价", "抄底"]
  },
  "outcome": null
}
```

结果标签（`outcome`）在持有期结束后补：

```json
{
  "horizon": "12m",
  "returnPct": 8.4,
  "benchmark": "csi300",
  "excessPct": 2.1,
  "maxDrawdownPct": -18.2,
  "labeledAt": "2026-01-02"
}
```

## 指标

| 指标 | 口径 |
| --- | --- |
| 流程分 | `eval.md` 的五维评分，满分 10，<7 不通过 |
| 绝对回报 | 区间总回报（含分红再投入） |
| 超额 | 相对沪深 300 / 行业指数 / 恒生指数 |
| 最大回撤 | 区间内最大回撤 |
| 下行捕获 | 基准下跌时的相对跌幅 |
| 校准度 | 输出「可进 / 观察 / 不碰」与实际结果是否匹配 |
| 拒绝质量 | 被判「不碰/观察」的标的，后续是否真的更差 |

**样本量警告**：少于 30 个独立案例时，不要用命中率下结论；报告样本数、区间和基准。
结果变差不代表框架错，可能只是市场风格；结果变好也不代表可复制。

## 先做这三件事

1. 冻结 30~50 个历史案例（含 `as_of` 和 `horizon`），先跑当前版本拿基线；
2. 用**当时可得**的股价、财报、股息率，不能用今天的数字回看；
3. 新版本必须满足：流程分不降 + 结果不显著变差 + 拒绝质量不降，才保留。

## 运行记录

每次跑完在 `runs/` 下留一份 JSON/Markdown：日期、模型、题目版本、逐题得分、失败原因。
不要只记总分。
