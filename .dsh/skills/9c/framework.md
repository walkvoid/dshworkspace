# 框架细则：三因子、硬规则与字段对照

本文件把"他的选股思路"翻译成可执行步骤。回答时逐表填，**不要跳过任何一栏**；
填不了的栏写"缺数据"，并说明它对结论的影响方向。

## 0. 先确认组合层级

| 问题 | 不合格时的标准回答 |
| --- | --- |
| 半年以上生活费是否已放在无回撤资产（短融 ETF / 逆回购 / 货币基金） | "先把这层做完，个股现在不该出现在你的清单里。" |
| 股息收入是否已覆盖刚性支出的 30% 以上 | "还没到谈第三步的时候，先做现金流。" |
| 这笔钱是不是后续增量资金（不是原有组合） | "第三步只用增量资金，不动存量。" |

三层顺序：流动性保障 → 现金流打造 → 高值博率投资。个股属于第三步之前/之外的事，
且第三步本身只买宽基 ETF。

## 1. 因子一：商业模式（定性，5 条判据）

| 判据 | 通过标准 | 证据来源 |
| --- | --- | --- |
| 垄断性/壁垒 | 别人进不来，且有提价权 | 行业格局、毛利率趋势 |
| 周期性 | 利润不受大宗价格、利率强驱动 | 营收/利润波动、行业属性 |
| 毛利率与定价权 | 高毛利且能提价 | `fundamentals.netMargin`、历史毛利率 |
| 变量数量 | 影响利润的变量少且可预测 | 业务结构、监管与政策敞口 |
| 负债结构 | 低负债，不怕加息 | `fundamentals.debtRatio`、`interestDebtRatio` |

判定：5 条里通过 ≥4 条 = 极优；3 条 = 良好；≤2 条 = 差。
**注意**：金融、地产、公用事业要用行业口径看负债，不能直接比制造业的负债率。

## 2. 因子二：穿透回报率（定量）

```
穿透回报率 = (正常化净利润 × 最低股息支付率) / 总市值
```

- 正常化净利润：最近一个完整财年的归母净利润（脚本 `derived.normalizedNetProfitYi`）。
- 最低股息支付率：可得财年里 `派息总额 / 归母净利润` 的最小值（`derived.minimumPayoutRatio`）。
  用最小值而不是平均值——他问的是"就算公司按最抠的方式派息，我能拿回多少"。
- 总市值：`quote.totalCapYi`。
- 结果：`derived.penetrationReturn`。

| 穿透回报率 | 他的态度 |
| --- | --- |
| ≥ 10% | 闭眼买（百胜中国 230 港币时的量级） |
| 6%~10% | 值得研究，考虑建仓 |
| 3%~6% | 只能算收息，够不上"高值博率" |
| < 3% | 不在体系内 |

**港股注意**：港股分红来自港交所派息公告解析，带 `exDate` 与宣派币种；宣派常为人民币、股价为港币，
脚本已按 `HKDCNY` 折算后再算股息率与穿透回报率（`fxRate` / `marketCapCnyYi` / `dividendCurrency` 可引用）。
派息率只统计派息记录数与最多年份一致的财年——最老的财年常常只抓到一半派息，必须剔除，
否则"最低派息率"会被残缺年份压低。残缺财年被剔除时，`payoutByFiscalYear` 的年份数会少于 3，说明这一点。

## 3. 因子三：真实可支配现金变动（定性 + 定量，一票否决）

口径三原则：

1. **极端保守主义**：所有资本开支（维持性 + 扩张性）、并购，一律视为现金流出。
2. **极端短视主义**：只看当年实际到账的现金变动，不做跨期平滑。
3. **脱离会计科目看本质**：理解每个科目背后的含义，而不是套一个统一公式。

脚本给的 `derived.freeCashFlowProxyYi` = 经营现金流净额 + 投资现金流净额，只是**代理值**。
使用时要说明：它没有单独剔除"维持性资本开支"，也没有还原一次性损益；对并购多的公司偏乐观。

**一票否决**：算出来为负（或无法判定为负）→ 直接放弃，不论前两个因子多好。

## 4. 仓位映射

| 商业模式质量 | 单票上限 | 场景 |
| --- | --- | --- |
| 极优（垄断、非周期、低负债） | 20%~40% | 腾讯（200 港币时）、优质公用事业 |
| 良好（品牌/渠道壁垒） | 10%~20% | 伊利、五粮液 |
| 周期股 | 5%~10% | 造纸、航运、资源 |
| 高杠杆 / 高法律风险 | ≤5%，通常不碰 | 地产、教育、保险等高杠杆金融 |

## 5. 市场水位与弹性（组合层，不看个股）

| 市场位置 | 动作 |
| --- | --- |
| 严重低于历史均值 | 扩大弹性：换入波动更大的优秀公司 |
| 正常区间 | 维持稳定收息 |
| 严重高于均值 | 降低弹性：换入波动更小的标的 |

参考信号（2025 年视频举例，注意通胀会让绝对点位失效，可用 5 年分位替代）：
上证 < 3000 定投沪深 300；恒生科技 < 4000 定投恒生互联网 ETF；回到均值以上分批卖出。

## 6. 虚高估值机会（反向筛选）

表面 PE 很高甚至亏损，但实际盈利能力强的标的。三个识别条件，缺一不可：

1. 非经常性损益是**一次性、短期**的（不是行业政策性的永久破坏）；
2. 对存量资产结构**不构成致命威胁**（罚款/减值不伤本金）；
3. 还原后仍有**足够安全边际**（对正常利润打折后依然便宜）。

典型：香港 REITs（强制分红 90%+，一旦利润转正就大规模派息）、商誉减值导致账面亏损但扣非盈利的公司。

## 7. 数据字段对照（脚本输出 → 框架输入）

| 框架输入 | 脚本字段 |
| --- | --- |
| 现价 | `quote.price` |
| 总市值（亿元） | `quote.totalCapYi` |
| PE(TTM) / PB | `quote.peTtm` / `quote.pb` |
| 最近财报归母净利润（亿元） | `fundamentals[0].netProfitYi`、`netProfitYoY` |
| 资产负债率 | `fundamentals[0].debtRatio` |
| 有息负债率 | `fundamentals[0].interestDebtRatio` |
| ROE | `fundamentals[0].roe` |
| 经营现金流净额 | `fundamentals[0].ocfYi` |
| 投资现金流净额 | `fundamentals[0].icfYi` |
| 正常化净利润（上一个完整财年） | `derived.normalizedNetProfitYi`、`normalizedNetProfitYear` |
| 历年派息率 | `derived.payoutByFiscalYear` |
| 最低派息率 | `derived.minimumPayoutRatio` |
| 穿透回报率 | `derived.penetrationReturn` |
| TTM 股息率 | `derived.dividendYieldTtm` |
| 自由现金流代理 | `derived.freeCashFlowProxyYi` |

## 8. 结论判定顺序（不可调换）

```
1) 组合层级不合格        -> 停，先做前两步
2) 因子三为负 / 不可判定  -> 不碰（一票否决）
3) 商业模式 ≤2 条        -> 不碰或 ≤5%
4) 穿透回报率 < 3%       -> 不在体系内
5) 以上都过              -> 进现金流仓，给仓位上限
```
